# Benchmarks

Every number here is regenerated by one of the three benchmarks —
`benchmarks/level0_physics.py`, `benchmarks/device_model_3d.py` and
`benchmarks/device_model_cad.py` — per the ecosystem benchmark standard
(warm-up, repeated samples, percentiles, one row per backend, unavailable
backends marked explicitly, provenance in the artefact).

## Level-0 physics

The operation is one pass
over a synthetic parameter grid evaluating, per point, the diamagnetic
mirror ratio, the ion loss boundary, the collisional time scales, both
confinement scalings, the FLR criterion, the adiabaticity parameter and
the tandem confinement chain; the time is reported per grid point and
includes the Python call overhead of both backends (the native backend is
called per point through its binding, so this measures the call-through
cost of the kernels, not a vectorised scan). Both backends evaluate the
transcendental functions through the pinned shared kernel library
(ADR 0006). Nothing here is a physics claim.

## Device 3D model tessellation — local workstation (non-isolated)

Regenerated by `benchmarks/device_model_3d.py`. The operation is one full
device pass: tessellating the ten bodies — nine of constant radius and one
profiled surface of revolution — at a declared segment count, then the
signed volume and surface area of every body. The time is reported per
generated face. Both backends are the pinned shared kernel library's: the
floor row builds the validated device model on its Python kernels, the
native row calls its native kernels per body through the binding, so this
measures call-through cost and not a vectorised pipeline. Nothing here is
a physics or engineering claim.

Artefact: `benchmarks/results/device_model_3d.local.json`

## Device CAD model operations — local workstation (non-isolated)

Regenerated by `benchmarks/device_model_cad.py`. Four operations on the
same declared assembly, on the one back-end there is: the pinned
third-party OpenCASCADE kernel through CadQuery. The composition timed is
the model's own, not a second copy of it. The record build includes the
tier-G1 reference tessellation and the per-body evidence, which is why it
costs more than the sum of the rows above it.

## Regenerate

```bash
make rust
VIRTUAL_ENV=.venv PATH=.venv/bin:$PATH maturin develop --release -m rust/Cargo.toml
.venv/bin/python benchmarks/level0_physics.py --points 100000 --warmup 3 --repeats 20 --label local
.venv/bin/python benchmarks/device_model_3d.py --segments 4096 --warmup 3 --repeats 20 --label local
.venv/bin/pip install -e ".[cad]"
.venv/bin/python benchmarks/device_model_cad.py --warmup 2 --repeats 10 --label local
```
